# Little Penguin, Snow Much Fun!

双击 Little-Penguin-Snow-Much-Fun.html 即可离线阅读。图片和 Patrick Hand 字体均已内嵌，无需联网。

9 幅原创无字拼贴插画，以用户提供的企鹅设定为角色参考。点击插画参与故事；Back / Next 翻页，左右方向键同样可用；结尾 Read again 重新开始。设备支持时可使用 Read aloud，英语语音由设备提供，不保证离线可用。

- originals/：9 幅无字 PNG 原图及用户角色参考
- assets/：保留完整构图的展示 JPEG
- story.json：英文文案、动作描述和互动反馈
- image-prompts.json：逐图生成提示词
- book.template.html、build.mjs：可编辑源文件；修改后运行 node build.mjs
- fonts/：Patrick Hand 原字体与 OFL 授权
- qa/：视口和交互检查结果、预览截图

主题是探索雪地游戏，模仿小步行走、滚雪球、拍拍雪等动作，以 Step, step. Here we go! 和对应动作变体建立跟读节奏。
